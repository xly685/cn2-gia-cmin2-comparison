## 三条线路分别是什么，各适合谁的宽带

CN2 GIA、9929、CMIN2 分别是中国电信、中国联通、中国移动三家自己的国际精品承载网，定位相同：比普通骨干网（电信 163、联通 4837、移动 CMI）拥堵程度低、晚高峰更稳。

**CN2 GIA（AS4809）**：中国电信下一代承载网，去程回程全程走精品网。第三方测评的观察是，这条线路多年来问题最少，普通线路晚高峰丢包率可达 30% 以上，而 CN2 GIA 基本还在正常区间。国内到洛杉矶电信用户平均延迟约 157ms，上海、杭州等沿海城市能压到 130ms 左右。顺带区分一个常见混淆点：CN2 GT 虽然也挂在 CN2 名下，但走的是 GT 层，2019 年后拥堵严重，官网自己都承认它和 163 网基本一样堵——认准 GIA，别被"CN2"两个字带偏。

**9929（AS9929）**：联通 A 网，签约单价约 $6000/Gbps，用的人少，拥堵程度低。NodeSeek 上有用户这样总结：“AS9929目前联通晚高峰使用仍然是强于CMIN2和CN2 GIA的，因为它只是老网，仅仅是签约单价比较高，所以拥堵程度要好很多。”联通用户晚高峰延迟基本稳定在 160ms 左右。它有个明显的坑：电信用户访问 9929 线路的机器，去程仍走电信 163 网，晚高峰照样堵，只有回程走 9929——所以电信用户买纯 9929 线路的机器体验会打折扣。

**CMIN2（AS58807）**：移动 2022–2023 年推出的精品骨干网，QoS 优先级比普通 CMI（AS58453）高，晚高峰表现稳定得多。在搬瓦工这里，移动用户的关键词就是 DC6 和 DC9：这两个洛杉矶机房已接入 CMIN2，第三方路由测评显示北京移动回程约 127ms，出洛杉矶直接进入 AS58807 节点经上海入网。

一句话决策：你家是电信宽带，看 CN2 GIA；联通宽带，看 9929；移动宽带，看回程是否走 CMIN2（58807）而不是 CMI（58453）。
